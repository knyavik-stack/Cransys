# 📚 Документация и спецификации архитектуры Cransys

Данная папка содержит структурированную техническую документацию, спецификации модулей и стратегические дорожные карты проекта.

## 📑 Содержание

1. **[06_ANALYTICS_AND_INSIGHTS_SPEC.md](./06_ANALYTICS_AND_INSIGHTS_SPEC.md)**  
   Спецификация модуля глубокого семантического анализа поисковых запросов и минус-слов.

2. **[AI_FUTURE_ROADMAP.md](./AI_FUTURE_ROADMAP.md)**  
   Фундаментальная дорожная карта развития AI-моделей (Gemini) в проекте:
   - Семантический аудит и автогенерация минус-слов;
   - AI-блеклист паразитных площадок и мобильных приложений РСЯ;
   - Анализ связки «Объявление → Посадочная страница»;
   - Предиктивный AI-ребалансировщик бюджета;
   - AI Direct Copilot (диалоговый ассистент для собственника).

3. **[07_BILLING_AND_WHITELABEL_SPEC.md](./07_BILLING_AND_WHITELABEL_SPEC.md)**  
   Спецификация биллинга (ЮKassa / Банковские карты / СБП), тарифной сетки (Экспресс, PRO, MAX) и генерации кастомизированных коммерческих PDF-отчетов с White-label брендингом для агентств и специалистов.

---
*Обязательные операционные файлы статуса (`_СТАТУС.md`, `changelog.md`, `_ПРОМПТЫ_ИСТОРИЯ.md`) и дизайн-система (`maket/`) размещены в корне репозитория согласно регламенту проекта.*
