# 📌 Статус проекта Cransys

**Дата обновления:** 20 сентября 2026 г.  
**Текущая фаза:** Спринт 4 (Аналитический дашборд AdminLTE на 100% реальных данных, Автоматические оповещения Telegram/Email, Хранилище отчетов Cloudflare R2, ЮKassa Webhooks и 54-ФЗ)  
**Репозиторий:** `knyavik-stack/cransys`  
**Стек:** Next.js 15 (App Router, React 19, TypeScript), Tailwind CSS, Server-Side Data Stores, Neon PostgreSQL (Drizzle ORM), Nodemailer (Yandex SMTP), Telegram Bot API, Cloudflare R2, Yandex Direct API v5 OAuth, ЮKassa.
