# 🎨 Дизайн-система и правила UX Cransys (Light Mode Premier)

Папка `maket` содержит правила визуального оформления, макеты и UX-принципы для проекта Cransys.

## 1. Цветовая палитра
- **Фон страницы:** `#F8FAFC` (Slate 50)
- **Контейнеры / Карточки:** `#FFFFFF` (Белоснежный)
- **Границы:** `#E2E8F0` (Slate 200)
- **Текст основной:** `#0F172A` (Slate 900)
- **Текст вторичный:** `#475569` (Slate 600)
- **Бренд / Фокус / Кнопки CTA:** `#2563EB` (Sapphire Blue), hover: `#1D4ED8`
- **Сливы бюджета / Ошибки:** `#DC2626` (Красный Loss 500), фон `#FEF2F2` (Loss 50)
- **Успех / Сохраненные деньги:** `#16A34A` (Зеленый Success)

## 2. Типографика
- Заголовки: Геометрический гротеск высокой читаемости
- Суммы в рублях и метрики: Моноширинный стиль (`font-mono`) для исключения смещения контента при обновлении чисел.

## 3. UX-правила
1. Загрузка файла в 1 клик (Drag & Drop + клик для выбора файла).
2. Экспресс-аудит выдает результат за < 2 секунд.
3. Прозрачность: формула «Факт → Флаг → Сумма потерь в рублях».
4. Никакой оценки компетентности специалистов — только цифры и технические факты настроек.
5. Соответствие 152-ФЗ: файл не содержит личных данных, хранится во временном хранилище и удаляется после проверки.
