# Changelog (История изменений) Cransys

Все изменения проекта документируются в данном файле.

## [1.0.0] — 2026-09-15
### Полнофункциональная Админка, CRUD пользователей, Конфигуратор тарифов и Защита отчетов
- **Полноценное управление пользователями в Панели Администратора (`/admin`):**
  - Создан бэкенд и UI для полного цикла управления учетными записями (`/api/admin/users`).
  - Возможность блокировки/разблокировки пользователей в один клик.
  - Удаление пользователей с модальным окном подтверждения.
  - Редактирование email, пароля, имени, лимитов отчетов, выручки и тарифа.
  - Ручное создание новых пользователей прямо из панели администратора.
- **Конфигуратор тарифов (`/api/admin/tiers`):**
  - Администратор может вручную изменять цены в рублях, лимиты проверок и включать/выключать модули (Direct API, AI-инсайты, кластеризация запросов, White-label PDF, корпоративная автоматизация) с моментальным сохранением в персистентную базу.
- **Реальная база пользователей и аналитика:**
  - Заменена имитация на реальное персистентное хранилище (`lib/db/users-store.ts` и `lib/db/tiers-store.ts`).
  - Все финансовые метрики (выручка, конверсии, средний чек, количество проверок) рассчитываются строго по реальным зарегистрированным пользователям.
- **Разграничение ролей и маршрутизация:**
  - Администратору закрыт доступ в клиентский дашборд с предупреждением и прямой кнопкой перехода в `/admin`.
  - В шапку сайта добавлена навигационная ссылка «Панель Admin» для учетных записей администраторов.
- **Защита отчетов и Paywall-гейтинг (`AuditResults.tsx`):**
  - Пользователи без оплаченного тарифа видят только поверхностные метрики (Индекс здоровья, сумму сливов, расход и число кампаний).
  - Детализация правил, факты, рекомендации, графики и экспорт PDF заблокированы и заблюрены с баннером оформления тарифа.
  - Для тестового суперюзера (`TESTER_ADMIN`) развернут 0 ₽ Sandbox переключатель всех 5 тарифов прямо в шапке отчета с полным доступом ко всем функциям без ограничений.
- **Полноценный контур авторизации:**
  - Реализована строгая валидация паролей при входе (`/api/auth/login`).
  - Добавлена страница восстановления пароля (`/forgot-password` и `/api/auth/reset-password`).
  - Добавлена регистрация новых пользователей (`/sign-up` и `/api/auth/register`).

## [0.9.6] — 2026-09-15
### Исправление гидратации и загрузки чанков в панели администратора
- Оптимизирован жизненный цикл рендеринга `app/admin/page.tsx` с использованием паттерна `useSyncExternalStore` для безопасного монтирования на клиенте.
- Устранена ошибка `ChunkLoadError` и предотвращен таймаут асинхронной загрузки чанков Recharts.
