# Changelog (История изменений) Cransys

Все изменения проекта документируются в данном файле.

## [0.4.0] — 2026-09-15
### Добавлено (Added)
- Разработан универсальный парсер выгрузок `lib/parser/excel-parser.ts`: поддержка CSV с разделителями `;`, `,`, `\t`, автодетекция кодировок Windows-1251 и UTF-8, синонимы колонок «Расход / Стоимость / Затраты / Списания / Cost», «Кампания / Название кампании / Campaign / Группа», определение типов площадок по ключевым словам и CTR.
- Добавлены 2 новых правила аудита: `Rule05CpaAnomaly` (аномально дорогая цена цели) и `Rule06LowCtrWaste` (слив на нецелевых запросах с микро-CTR < 0.6%). Порог кампаний с нулевыми конверсиями понижен до 1200 ₽ для отлова микросливов.
- Интегрирована бесплатная модель `gemini-3.8-flash` через `@google/genai` в `lib/ai/direct-analyst.ts` для глубокого экспертного аудита, выявления скрытых проблем и формирования персонального чеклиста директологу.
- Разработан компонент интерактивных графиков `components/AuditCharts.tsx` на `recharts`:
  - Круговая диаграмма (Donut Chart) с наглядным отображением доли слива в сетях (РСЯ);
  - Столбчатая диаграмма (Bar Chart) сравнения расхода и конверсий смартфонов против ПК;
  - Интерактивный калькулятор окупаемости с ползунком перераспределения бюджета и динамическим прогнозом доп. заявок (+12...+18 лидов в месяц);
  - Блок AI-инсайтов от Gemini с категоризацией проблем по степени критичности.

## [0.3.0] — 2026-09-15
### Добавлено (Added)
- Реализован генератор ТЗ подрядчику `components/ContractorTaskModal.tsx` с аргументированными требованиями по 4 правилам аудита, копированием в буфер и печатью.
- Добавлена страница личного кабинета и истории аудитов `app/dashboard/page.tsx` с подключением к Neon PostgreSQL через `/api/audit/history`.
- Внедрены оптимизированные стили для чистой печати/экспорта в PDF (`print:hidden`, автоформатирование А4 без лишних элементов интерфейса).
- В шапку `Header.tsx` добавлена навигация в «Кабинет / История».

## [0.2.0] — 2026-09-15
### Добавлено (Added)
- Установлены и интегрированы пакеты `xlsx`, `zod`, `@neondatabase/serverless`.
- Разработан парсер выгрузок Яндекс.Директ (`lib/parser/excel-parser.ts`) с автодетекцией колонок «Мастера отчетов» и «Статистики по кампаниям».
- Подключен реальный парсинг файлов в `DropZone.tsx` и эндпоинте `app/api/audit/route.ts`.
- Развернут маршрут инициализации таблиц Neon PostgreSQL (`/api/db/init`).
- Написан верификационный юнит-тест `tests/unit/audit-engine.test.ts`, подтверждающий детекцию слива 14 880 ₽ (98.9%) в РСЯ на эталоне «Меблирон».
### Добавлено (Added)
- Инициализирована каноническая файловая иерархия проекта по техкарте v2 (Neon + Clerk + Cloudflare R2).
- Настроены правила ассистента `.cursorrules` с фокусом на строгий TypeScript, архитектуру движка правил и Light Mode Premier UI.
- Созданы GitHub Actions CI/CD воркфлоу в `.github/workflows/`.
- Документирована дизайн-система и правила верстки в каталоге `maket/`.
- Созданы интерфейсы Движка Аудита Яндекс.Директ (`IAuditRule`, `RuleResult`, `CampaignData`).
- Сформирована Drizzle-схема базы данных для Neon PostgreSQL (`db/schema.ts`).
- Реализован первоначальный интерфейс главной страницы: Hero-секция с интерактивной Drag & Drop зоной загрузки выгрузок Яндекс.Директ, переключателем демо-данных (кейс «Меблирон») и мгновенным расчетом потерь.
- Исключена зависимость от Cloudflare R2: внедрена Zero-Card архитектура с on-demand генерацией PDF и хранением отчетов в бесплатном слое Neon PostgreSQL.
